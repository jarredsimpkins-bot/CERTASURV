Reviewed: July 22, 2026

## Quick Start

1. Sign in with the company Google account.
2. Open Google Drive and choose `Shared drives`.
3. Open `CERTASURV_PROJECT DRIVE`.
4. Open the project folder that matches the SSD job number and project name or address.
5. Open the inner `SSD` folder.
6. Use the numbered workflow folders. Courthouse research is in `02_COURTHOUSE_RESEARCH`; drafting files are in `04_OFFICE_DRAFTING`.

## How The Shared Drive Is Organized

Start at the shared drive, choose a project, then use the same numbered workflow folders inside that project.

Shared drive name:

`CERTASURV_PROJECT DRIVE`

At the root of the shared drive, most active jobs are project folders named with an SSD job number and a location. Examples include `SSD-11643-RT35` and `SSD-11641 - WINFIELD`. The drive also contains system folders such as `TEMPLATE`, `ARCHIVE`, `01FORMS`, `ESTIMATES`, and `00_CERTASURV_COMMAND_CENTER`.

Standard project folder tree:

```text
CERTASURV_PROJECT DRIVE
[SSD-##### - PROJECT NAME OR ADDRESS]
SSD
01_INTAKE_SCOPE
02_COURTHOUSE_RESEARCH
03_FIELD_WORK
04_OFFICE_DRAFTING
05_REVIEW_QC
06_DELIVERABLES
```

| Folder | Use |
| --- | --- |
| `01_INTAKE_SCOPE` | Client intake, job scope, proposal information, and starting documents. |
| `02_COURTHOUSE_RESEARCH` | Deeds, plats, tax maps, screenshots, parcel folders, and the master research log. |
| `03_FIELD_WORK` | Crew instructions, raw field data, photos, sketches, line marking, control, and stakeout files. |
| `04_OFFICE_DRAFTING` | Office notes, base files, DWG drawings, points, and exhibit PDFs. |
| `05_REVIEW_QC` | Review and quality-control work before delivery. |
| `06_DELIVERABLES` | Drafts and final deliverables. |

Rule: For normal job work, open the correct SSD project folder. Do not work from `TEMPLATE` or `ARCHIVE` unless a supervisor specifically tells you to do so.

## Find Courthouse And Parcel Files

Parcel research is organized inside each project. Parcel folders are commonly named by the full tax map number.

Correct courthouse path:

`CERTASURV_PROJECT DRIVE > [PROJECT] > SSD > 02_COURTHOUSE_RESEARCH > parcels > [TAX MAP NUMBER]`

Steps:

1. Open `CERTASURV_PROJECT DRIVE`.
2. Open the project folder. Match both the SSD job number and the project name or address.
3. Open the inner `SSD` folder.
4. Open `02_COURTHOUSE_RESEARCH`.
5. Open `parcels`.
6. Open the exact tax map number. Match the complete number, including leading zeros and the final suffix.

Example parcel folder name:

`28-11-0050-0126-0000`

A parcel folder may contain courthouse screenshots, tax-map images, GIS images, deeds, plats, and related research.

Useful courthouse folders:

- `00_MASTER_RESEARCH_LOG` - overall research notes and tracking for the project.
- `parcels` - individual parcel folders, normally named by tax map number.
- `plats` - plat images or grouped plat material when that folder is present.

Search tips:

- Search the shared drive using the full SSD job number when you cannot find the project.
- Search using the complete tax map number when a parcel folder is hard to spot.
- Double-check the project address before opening or downloading files from a similar job.

Note: A new or lightly researched project may not have a `parcels` folder yet. That usually means the parcel research has not been added or the material is still stored directly in `02_COURTHOUSE_RESEARCH`.

## Get The DWG And Points File

The drawing and point data are stored in the office-drafting base-files folder for the selected project.

Correct DWG and points path:

`CERTASURV_PROJECT DRIVE > [PROJECT] > SSD > 04_OFFICE_DRAFTING > 02_BASE_FILES`

What to look for:

| File type | Typical extension | Meaning |
| --- | --- | --- |
| Drawing | `.dwg` | CAD drawing used by AutoCAD or compatible drafting software. |
| Points | `.csv` or `.txt` | Survey point data. Populated base-files folders commonly include a CSV points file. |

Download from the browser:

1. Open `02_BASE_FILES` inside the correct project.
2. Select the DWG file, right-click it, and choose `Download`.
3. Select the matching points file, usually CSV or TXT, and download it.
4. Save the DWG and points file together in the same local job folder.
5. Open the local copies in the approved CAD or point-processing software after the download finishes.

Before opening or sending the files, confirm:

- Correct SSD job number.
- Correct project name or address.
- Latest intended DWG version.
- Matching points file downloaded.
- Local copies saved together.
- Source files left in place in Drive.

Protect the source files:

- Download a copy. Do not move, rename, replace, or delete shared Drive files unless a supervisor specifically directs you to do that.
- When several versions exist, confirm which version is current before working.

## Use Drive For Desktop

Drive for desktop puts Google Drive in Windows File Explorer or macOS Finder. The browser is still the safest choice for a one-time download.

Install and sign in:

1. Open https://www.google.com/drive/download/.
2. Run the installer.
3. Sign in with the company Google account that has access to the shared drive.
4. Open File Explorer or Finder.
5. Open `Google Drive > Shared drives > CERTASURV_PROJECT DRIVE`.
6. Choose the project, open `SSD`, and use the same numbered folders shown in this guide.

Computer path:

`Google Drive > Shared drives > CERTASURV_PROJECT DRIVE > [PROJECT] > SSD > ...`

Best practice for DWG work:

- Use Drive for desktop to find the file, but make a local working copy when directed by the office workflow.
- Keep the DWG and its points file together in the same local job folder.
- Do not drag shared-drive folders to another location. Dragging can move them for everyone if you have permission.
- When a file is only online, allow it to finish downloading before opening it in CAD software.

## Use Google Chat With Drive

Google Chat can be used in the browser at https://chat.google.com/ or installed from Chrome as a desktop web app.

Install Google Chat:

1. Open Google Chrome.
2. Go to https://chat.google.com/.
3. Sign in with the company Google account.
4. Click the install icon at the right side of Chrome's address bar.
5. If the icon is not visible, open Chrome's menu and choose `Install Google Chat`.
6. On Windows, open Chat later from Start. On a Mac, open it from Applications.

Send a Drive file in Google Chat:

- In Drive, open the correct project and locate the file or folder.
- Use `Copy link` or paste the Drive link into Chat.
- Do not change sharing permissions unless authorized.
- Include the SSD job number, project name, and a short description so the recipient knows exactly what the link is.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Shared drive is missing | Check the profile picture and switch to the company Google account. If it is still missing, access must be granted by the Drive administrator. |
| Project is hard to find | Search the full SSD job number first. Then confirm the project name or address. |
| DWG will not open in Drive | Download it and open the local copy in AutoCAD or the approved CAD program. |
| No Download option | You may not have download permission. Ask a supervisor or Drive administrator. |
| Chat install icon is missing | Make sure Chat is open in Chrome and you are signed in. Use Chrome menu > `Install Google Chat`. |

## Final Rules

- Use the correct company account.
- Confirm the SSD job number before opening, downloading, or sharing project files.
- Download copies instead of moving shared files.
- Never rename, move, replace, or delete a shared folder unless a supervisor tells you to do so.
